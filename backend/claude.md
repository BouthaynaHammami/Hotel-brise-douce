# DevUnity BriseDouce - Backend Microservices Architecture Context

This file serves as a reference guide and an architectural overview of the entire microservice ecosystem. Provide this document to AI models for context in future prompts.

## 1. Project Architecture Overview

The backend is built around a polyglot microservice architecture, primarily using **Spring Boot/Cloud** along with **FastAPI** for user management.

### Component Details
*   **API Gateway (Spring Cloud Gateway)**: Runs on port `8081`. Handles centralized routing, handles global Cross-Origin Resource Sharing (CORS) for the Angular frontend (`localhost:4200`), and serves as the single entry point.
*   **Service Discovery (Eureka Server)**: Runs on port `8761`. Handles dynamic service registration and discovery.
*   **Spring Boot Microservices**:
    *   `Gestion_avis_reclamations` -> `/avis_reclamations/api/**`
    *   `Gestion_chambres` -> `/chambres/api/**`
    *   `Gestion_clients` -> `/clients/api/**`
    *   `Gestion_nettoyage_maintenance` -> `/nettoyage_maintenance/api/**`
    *   `Gestion_personnel` -> `/personnel/api/**`
    *   `Gestion_reservations` -> `/reservations/api/**`
*   **FastAPI Microservice**:
    *   `Gestion_utilisateurs` -> Manages authentication (JWT-based), roles, and user lifecycle. Communicates with a MySQL database (`hotel_db_user`) via SQLAlchemy and XAMPP.

## 2. FastAPI Integration Configuration (How to make it compatible)

To ensure the FastAPI `Gestion_utilisateurs` microservice is fully compatible and recognizable by the Spring Cloud environment, the following simple configuration steps must be applied.

### A. Register FastAPI with Eureka Server
FastAPI needs to broadcast its address to Eureka (`http://localhost:8761/eureka`) so that the API Gateway can dynamically route traffic to it.

1.  **Install the client library** inside the `Gestion_utilisateurs` environment:
    ```bash
    pip install py-eureka-client
    ```
    *(Remember to add `py-eureka-client` to your `requirements.txt`)*

2.  **Update `Gestion_utilisateurs/main.py`** to connect on startup:
    ```python
    from fastapi import FastAPI
    from contextlib import asynccontextmanager
    import py_eureka_client.eureka_client as eureka_client

    # Define the application lifespan events
    @asynccontextmanager
    async def lifespan(app: FastAPI):
        # Register to Eureka upon server startup
        await eureka_client.init_async(
            eureka_server="http://localhost:8761/eureka",
            app_name="utilisateurs_service", # Service ID that Gateway will use
            instance_port=8000 # The operational port of FastAPI
        )
        yield
        # Unregistration is automatically handled on shutdown

    # Attach the lifespan to your app
    app = FastAPI(title="User Microservice - Flat Arch.", lifespan=lifespan)
    ```

### B. Configure API Gateway Routing
Currently, the FastAPI exposes routes at the root (e.g., `/login`, `/register`). However, requests arriving at the API Gateway will be prefixed to group the service (e.g., `/utilisateurs/api/login`). 

In `API_Gateway/src/main/resources/application.properties`, append the following lines to map and rewrite the route:

```properties
# Gestion Utilisateurs Service (FastAPI)
spring.cloud.gateway.routes[6].id=utilisateurs_service
spring.cloud.gateway.routes[6].uri=lb://utilisateurs_service
spring.cloud.gateway.routes[6].predicates[0]=Path=/utilisateurs/api/**
# Important: Strip the prefix so FastAPI receives /login instead of /utilisateurs/api/login
spring.cloud.gateway.routes[6].filters[0]=RewritePath=/utilisateurs/api/(?<segment>.*), /$\\{segment}
```

### C. CORS Management Notice
The API Gateway is already configured to inject global CORS headers to HTTP responses (allowing `http://localhost:4200`). To prevent "Multiple CORS Headers" browser errors, you might need to completely remove or bypass the `CORSMiddleware` setup currently present in `Gestion_utilisateurs/main.py` if the Gateway sits entirely in front of it.

## 3. Key Notes for Future Prompts

If you request features or debugging from AI models in the future, please mention:
*   **Authentication Flow**: The JWT Access Token is generated by the FastAPI `Gestion_utilisateurs` service on `/login`. API Gateway currently exposes the `Authorization` header to all downward microservices.
*   **Security Propagation**: Since Spring Boot services need to protect their resources, they must either validate the FastAPI JWT token locally using passing symmetric keys (Secret String) or call a verification proxy.
*   **Polymorphism Setup**: User entity relies on SQLAlchemy's inherited polymorphism rules. The models in `Gestion_utilisateurs` use a `type_utilisateur` discriminator. Ensure synchronization when handling cross-microservice schema constraints.
*   **Routing Concept**: Always assume the Angular frontend communicates *strictly* with `http://localhost:8081` (Gateway Gateway) and relies on the Gateway's internal mapping to `lb://<service-name>` logic.
